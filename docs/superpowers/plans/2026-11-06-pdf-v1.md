# PDF v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aplicativo desktop offline que importa, visualiza, monta e exporta PDFs (escopo A).

**Architecture:** `core/` puro Python (PyMuPDF + pikepdf) com modelo de páginas virtual e exportação em duas etapas; `ui/` PySide6 consome o `core/`.

**Tech Stack:** Python 3.14, PySide6 6.12, PyMuPDF, pikepdf 10, pytest, pytest-qt.

**Spec:** `docs/superpowers/specs/2026-11-06-pdf-v1-design.md`

## Global Constraints

- `core/` nunca importa PySide6.
- Arquivo original importado nunca é modificado; tudo trabalha sobre cópias no workspace.
- `offline.enable()` é chamado em `app.py` antes de qualquer outra importação do app.
- Textos de interface em português do Brasil.
- Senha usa AES-256 (`pikepdf.Encryption(R=6)`).

## Review Focus

- PDF com senha na importação: pedir senha; senha errada não importa.
- PDF corrompido: reparo pelo pikepdf; se falhar, `ImportError_` com mensagem clara.
- Intervalo de páginas inválido ("5-2", "0", "99" num doc de 3 páginas): `ValueError` antes de gravar.
- Exportar documento vazio: `ValueError("Documento sem páginas")`.
- Nome de arquivo repetido no spool/workspace: sufixo numérico, nunca sobrescreve.

### Task 2: Modelo de documento e histórico

**Files:** Create `core/document.py`, `core/history.py`, `core/ranges.py`, tests correspondentes.

**Interfaces — Produces:**
- `@dataclass(frozen=True) PageRef(source: Path, index: int, rotation: int = 0)`.
- `Document`: `.pages: list[PageRef]`; `.add_source(path: Path) -> None` (anexa todas as páginas); `.move(src: list[int], dest: int)`; `.rotate(idx: list[int], degrees: int)` (múltiplo de 90, normaliza 0..270); `.delete(idx: list[int])`; `.snapshot() -> tuple[PageRef, ...]`; `.restore(snap)`.
- `History(doc: Document)`: `.record()` antes de cada mudança; `.undo() -> bool`; `.redo() -> bool`.
- `parse_ranges(text: str, n_pages: int) -> list[list[int]]` — "1-3, 5" retorna `[[0,1,2],[4]]`; inválido levanta `ValueError`.

- [ ] Testes: move `[0]` para fim em doc de 3 páginas resulta na ordem `[1,2,0]`; rotate 90 duas vezes resulta 180; rotate 270+90 resulta 0; undo/redo restauram; `parse_ranges("5-2", 5)`, `("0", 3)`, `("9", 3)` levantam `ValueError`.
- [ ] Implementar; PASS; commit `feat: modelo de documento, histórico e intervalos`.

### Task 3: Motor PyMuPDF

**Files:** Create `core/engines/__init__.py`, `core/engines/mupdf.py`, `tests/test_mupdf.py`

**Interfaces — Produces:**
- `page_count(path: Path, password: str | None = None) -> int`
- `needs_password(path: Path) -> bool`
- `render(path: Path, index: int, zoom: float, rotation: int = 0, password: str | None = None) -> bytes` (PNG).
- `image_to_pdf(img: Path, out: Path) -> Path`

- `add_page_numbers(path: Path, fmt: str = "{n} / {total}") -> None` (rodapé centralizado, fonte 9, salva incremental-free via arquivo temporário).

- `compress_images(path: Path, dpi: int = 150, quality: int = 70) -> None`
- `decrypt_to(path: Path, password: str, out: Path) -> Path`

- [ ] Testes: `build` de 2 PDFs (2+3 páginas) com rotação 90 na primeira resulta 5 páginas e rotação 90; texto extraído da página 1 do resultado contém "Página"; numeração faz `get_text()` conter `"1 / 3"`; marca d'água adiciona o texto; `image_to_pdf` gera 1 página; `render` retorna bytes que começam com `\x89PNG`.

### Task 4: Motor pikepdf

**Files:** Create `core/engines/qpdf.py`, `tests/test_qpdf.py`

**Interfaces — Produces:**
- `repair(src: Path, out: Path) -> Path` (`pikepdf.open` + `save`; falha levanta `PdfRepairError`).
- `optimize(path: Path, linearize: bool = True) -> None` (`compress_streams=True`, `object_stream_mode=generate`, `recompress_flate=True`).
- `protect(path: Path, user_pw: str, owner_pw: str | None = None, allow_print: bool = True, allow_copy: bool = False) -> None`
- `unprotect(path: Path, password: str, out: Path) -> Path`
- `read_metadata(path: Path) -> dict[str, str]`
- `strip_metadata(path: Path) -> None` (remove `/Info` e XMP).

- [ ] Testes: protect, depois `pikepdf.open` sem senha levanta `PasswordError`, com senha abre; unprotect gera arquivo que abre sem senha; strip remove `/Author` previamente gravado; arquivo truncado: `repair` levanta `PdfRepairError` ou devolve PDF válido.
- [ ] Implementar; PASS; commit `feat: motor pikepdf`.

### Task 5: Importação, exportação e divisão

**Files:** Create `core/importer.py`, `core/export.py`, `tests/test_export.py`

**Interfaces — Produces:**
- `import_file(ws: Workspace, src: Path, password: str | None = None) -> Path` — copia para o workspace; imagem (`.png .jpg .jpeg .bmp .tif .tiff .webp`) vira PDF; PDF ilegível passa por `repair`; com senha e `password` correta salva versão decifrada; sem senha levanta `PasswordRequired`; senha errada levanta `WrongPassword`.
- `@dataclass ExportOptions(page_numbers: bool=False, watermark: str|None=None, compress: Literal["none","lossless","lossy"]="lossless", linearize: bool=True, strip_metadata: bool=False, password: str|None=None)`
- `export(doc: Document, out: Path, opts: ExportOptions) -> Path` — ordem: build, numeração, marca d'água, compress lossy, optimize, strip, protect. Documento vazio levanta `ValueError("Documento sem páginas")`.
- `split(doc: Document, ranges: list[list[int]], out_dir: Path, stem: str, opts: ExportOptions) -> list[Path]` — nomes `{stem}_parte1.pdf`...

- [ ] Testes: export com todas as opções resulta em PDF protegido cuja abertura com senha mostra numeração; split "1-2,3" de 3 páginas gera 2 arquivos (2 e 1 páginas); export vazio levanta `ValueError`; import de PDF com senha sem `password` levanta `PasswordRequired`.
- [ ] Implementar; PASS; commit `feat: importação, exportação e divisão`.

### Task 6: Spool da impressora virtual

**Files:** Create `core/printer.py`, `scripts/setup_printer.ps1`, `tests/test_printer.py`

**Interfaces — Produces:**
- `SPOOL_DIR = Path(os.environ["LOCALAPPDATA"]) / "ILoveFMTLY" / "spool"`
- `ensure_spool(dir: Path = SPOOL_DIR) -> Path`
- `collect(ws: Workspace, dir: Path = SPOOL_DIR) -> list[Path]` — move cada `*.pdf` completo (tamanho estável e começa com `%PDF`) para o workspace com nome `Impressão AAAA-MM-DD HHMMSS.pdf`, único.
- `setup_printer.ps1`: `Add-PrinterPort -Name "$env:LOCALAPPDATA\ILoveFMTLY\spool\print.pdf"`; `Add-Printer -Name "ILoveFMTLY PDF" -DriverName "Microsoft Print To PDF" -PortName <porta>`; parâmetro `-Remove` desinstala.

- [ ] Testes: `collect` move PDF válido e ignora arquivo que não começa com `%PDF`; dois arquivos coletados no mesmo segundo não colidem.
- [ ] Implementar; PASS; commit `feat: spool da impressora virtual`.
